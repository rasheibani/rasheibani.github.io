Applied AI · Parks Victoria01

Evaluation-gated LLM code migration

An AI-assisted, test-driven pipeline that translates legacy Oracle PL/SQL and Oracle Spatial logic to PostgreSQL/PostGIS. Model output is never trusted by default.

  • Microsoft Foundry-hosted models and GitHub Copilot CLI, with retrieval over a curated migration knowledge base and strict JSON response contracts
  • Every candidate must pass syntax, dependency, structural, spatial, behavioural and security gates, then human review
  • Bounded retries, immutable evidence, resumable state; audit defects turned into regression gates
  • 775 validated SQL objects deployed in dependency order with SHA-256 checksums via Azure DevOps

Research · PhD02

Deep RL agents that test route instructions

Reinforcement learning agents act as simulated users to check whether natural-language navigation instructions can actually be followed in complex buildings.

  • PPO and DQN agents (PyTorch, Stable-Baselines3, Gymnasium, TextWorld) with curriculum learning
  • 742 synthesised indoor environments; training runs up to 1M iterations on A100 GPU clusters
  • Evaluation harness with statistically significant gains over baselines; published in IJGIS and JOSIS

Production validation for an AI-assisted cloud migration

The engineering around the LLM pipeline: an evidence-based, restartable runbook that moved a corporate database to Azure PostgreSQL with production kept read-only throughout.
